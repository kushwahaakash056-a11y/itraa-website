# ITRAA Aura Project

Create a 100% ORIGINAL premium luxury perfume brand website for a fragrance brand named "ITRAA".

DO NOT copy any existing website.

The website should have the same premium feeling as brands like Maison Francis Kurkdjian, Byredo, Jo Malone, Diptyque, Le Labo, Dior Beauty and Tom Ford while maintaining a completely unique layout and identity.

The overall experience should feel elegant, editorial, modern, luxurious, sophisticated and award-winning.

The website should look like an Awwwards Website of the Day.

==================================================

TECH STACK

==================================================

Use:

• React (Vite)

• Tailwind CSS

• GSAP

• GSAP ScrollTrigger

• Lenis Smooth Scroll

• Framer Motion (only for micro interactions)

• Lucide React Icons

• Responsive Design

• Component Based Architecture

Code should be clean, reusable and production ready.
